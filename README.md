# Gerador de Gráficos em C

Projeto desenvolvido em C para gerar gráficos de barras diretamente no terminal a partir de valores fornecidos pelo usuário.

## Funcionalidades

- Entrada de quantidade variável de valores
- Suporte a valores positivos e negativos
- Validação dos valores inseridos
- Identificação do maior e menor valor
- Geração de gráfico diretamente no terminal
- Identificação dos valores no eixo X

## Como executar

Compile o arquivo `gerador_de_graficos.c` utilizando um compilador C.

Exemplo:

```bash
gcc gerador_de_graficos.c -o gerador_de_graficos
